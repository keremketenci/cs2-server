# Pterodactyl panel settings

The egg variables live in the panel's database, not in any server file, so they are written down here by hand.
Update this file whenever a value is changed in the panel (Startup tab).

Secrets are never written here: GSLT, Steam Web API key and RCON password are only in the panel.

Last checked: 2026-11-01.

## Docker image

`KitsuneLab CS2 - GitHub - Unlimited`

## Startup command

Generated by the egg from the variables below (secrets replaced with `<...>`):

```
$( sh custom_files.sh >&2 ) ./game/cs2.sh -dedicated -ip 0.0.0.0 -port 27015 -authkey <STEAM_WEB_API_KEY>
+map de_dust2 -maxplayers 12 +sv_setsteamaccount <GSLT> +game_type 3 +game_mode 0
+hostname "Ghost Territory CS2 Server" $( [ -n "" ] && printf '%s' '+sv_password ""' )
$( [ "1" == "1" ] && printf '%s' ' -usercon' ) $( [ "1" == "1" ] || printf '%s' ' -insecure' )
+sv_hibernate_when_empty false
```

`$( sh custom_files.sh >&2 )` is our own addition: it runs `48b4a3c2-.../custom_files.sh` (copies `custom_files/`
into `game/csgo/`) before the game starts.

## Variables

| Variable | Value | Why |
|---|---|---|
| Max Players | `12` | |
| Disable Updates | `0` | `SRCDS_STOP_UPDATE`. `1` would skip only the SteamCMD CS2 update (and Validate Install), Metamod and CounterStrikeSharp still update on every start, and after a Valve CS2 update players could not join. Keep `0` |
| Validate Install | `0` | Set to `1` for one start only when game files are broken |
| Game Server Login Token (GSLT) | set (secret) | Public server listing. Created at steamcommunity.com/dev/managegameservers |
| Map | `de_dust2` | Start map only, GameModeManager takes over after that |
| Game Type / Game Mode | `3` / `0` (Custom) | GameModeManager modes run on the custom game mode (`cfg/gamemode_custom_server.cfg`) |
| Metamod:Source | on | Needed by CounterStrikeSharp and MultiAddonManager |
| CounterStrikeSharp | on | All our plugins |
| SwiftlyS2 | off | Not used |
| ModSharp | off | Not used, incompatible with CounterStrikeSharp |
| Allow Prerelease Updates | off | Only stable CSS / Metamod |
| Console Filter | off | Patterns in `egg/configs/console-filter.json` (only "Certificate expires" for now) |
| Custom Parameters | empty | |
| Auto Cleanup | on | Rules in `egg/configs/cleanup.json` (old logs, demos, backup rounds, core dumps) |
| Enable VAC | on | |
| Enable RCON | on | Adds `-usercon`. Turn off if no external RCON tool is used |
| RCON Password | set (secret, read only) | |
| Server Name | `Ghost Territory CS2 Server` | |
| Server Password | empty | Public server |
| Hibernate When Empty | off | Hibernation also pauses CounterStrikeSharp timers and GameModeManager's rotation |
| Steam Web API Key | set (secret, read only) | `-authkey`, needed to download workshop maps |
| Custom Files | `1` | Our addition to the egg (`CUSTOM_FILES_ENABLED`): `custom_files.sh` copies `custom_files/` on every start. Must stay on |

## Not in git

`egg/versions.txt` (Metamod / CSS versions the egg installed) is rewritten by the egg on every update,
so it is ignored. The real versions are on the server.
